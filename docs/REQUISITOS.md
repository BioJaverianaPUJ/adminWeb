# Trazabilidad con el SRS

Referencia: Proyecto_de_Grado___Biojaveriana (3).pdf, 59 páginas. Revisadas las interfaces web (páginas PDF 31–33), las funcionalidades administrativas (46–51) y los requisitos no funcionales (52). Backend contrastado con `origin/main`, commit `8e9c221488b5182ff6daec327226f68761a7ad19`, el 4 de noviembre de 2026.

«Integrado» significa que el código llama al contrato verificado. Las pruebas de escritura se ejecutaron contra dobles controlados; falta aceptación con una cuenta ADMIN real en un ambiente de pruebas.
